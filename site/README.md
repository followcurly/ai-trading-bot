# Public site (`site/`)

Next.js front door for **[tradebot.followcurly.com](https://tradebot.followcurly.com)**: landing, **`/flow`**, **`/architecture`**, **`/research`** (method). Safe for the public internet (`check:public` runs before build).

- `npm install` then `npm run dev` from **`site/`**
- Deploy: Vercel **Root Directory = `site`**. Set **`NEXT_PUBLIC_SITE_URL=https://tradebot.followcurly.com`**
