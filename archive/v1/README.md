# v1 archive (not imported by the live bot)

v1 tried regime models, an LLM decision brain (Claude), options ladders, and a
weekly Sonnet review. It was retired for v2 (red-day buy & hold, no LLM in the loop).

Kept here for reference and receipts. Nothing under `archive/` is on the
`trader` import path; v1 trade history still lives in `data/logs/trades.db` and is
summarised by `trader/v1_summary.py` for the dashboard.

- `trader/` — v1 modules (brain, risk engine, options executor, data feeds, reporting, research, tax)
- `scripts/` — v1 probes and offline reports
